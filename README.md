# Elevance Embedded Systems Internship

ESP32-based smart embedded monitoring and protection system developed during the Elevance Internship using Wokwi simulation platform.

The project focuses on intelligent battery monitoring, event-driven safety protection, diagnostics, fault tolerance, cloud telemetry and executive dashboard integration using embedded systems architecture.

---

# Technologies Used

* ESP32
* Embedded C/C++
* Arduino Framework
* Wokwi Simulation
* I2C LCD
* Relay Module
* Buzzer
* Serial Monitoring

---

# Internship Tasks

## Task 1 – Adaptive Battery Intelligence Engine

Features:

* Multi-cell voltage monitoring
* Battery imbalance detection
* Battery health classification
* Fault detection system

## Task 2 – Event-Driven Safety Protection Kernel

Features:

* millis()-based non-blocking execution
* Event-driven state machine
* Relay protection system
* Recovery logic
* Anti-relay chatter protection
* LCD diagnostics and buzzer alerts
